# OOPD-A1
This assignment contains basic programming practices without using standard C/C++ library

1. Setting up a git repository
2. Writing a C++ program which returns 0, but compiled without library files
3. Writing a program using .S file, which asks for an input and gives response accordingly
4. Dynamically allocating memory for names without overflow, on a new branch
5. Extending it to allow resizing the allocation
